# Why there is no front end

A trusted privacy operator asks for the next assessments, overdue requests, stale reviews or missing retention evidence. The CLI reads one database. Coding agents can add a field or report with a tested migration.

Read-only HTML reports show the weekly position. Branded paperwork prepares assessment and request briefs. Neither is a public portal, mobile app, offline multi-user client or drag-and-drop workflow builder. There is no discovery crawler, cookie banner, redaction engine or automatic request fulfilment.

A shared hosted database needs access controls and an operating plan. Enterprise DNA can build team screens and approved connections as part of your version, then operate them through Omni by Enterprise DNA for a setup fee and a retainer. The private free base remains useful to the operator without them.
